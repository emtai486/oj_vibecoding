Problem Set

登录后查看题库

题目列表、完成状态和提交入口统一放在登录后的训练工作台中，公开首页只保留平台介绍和账号入口。

Editor

浏览器内完成提交

题目详情页集成 CodeMirror 编辑器，支持 C++17 代码提交和判题结果回显。

Admin

后台维护题目

管理员可维护题目、难度、测试用例和资源限制，前台训练页面自动读取最新数据。

Training Flow

从题库到判题结果

开始训练
01

进入题库

登录后查看全部题目，按难度和完成状态快速定位下一道训练题。

02

阅读题面

题目详情集中展示输入输出格式、样例、时间限制和内存限制。

03

提交代码

在浏览器编辑 C++17 程序，提交后由后端编译运行隐藏测试用例。

04

记录状态

通过后在当前浏览器标记为已完成，回到题库时可以继续规划训练进度。

Student Mode

普通用户训练

适合课程作业、算法入门和小规模练习场景。用户登录后只看到训练相关入口，界面保持专注。

  • 题库浏览与题目详情
  • C++17 在线提交
  • 本地通过状态记录
Admin Mode

管理员也可提交

管理员保留新增、删除题目的权限，同时可以直接进入题库练习并提交代码，便于验题和回归检查。

  • 题目与测试用例维护
  • 后台列表一键进入练习
  • 共享同一套判题流程
Judge Runtime

面向教学场景的轻量级 OJ

后端使用 C++ 服务提供静态页面和 JSON API，题目与测试用例持久化到 MySQL，提交时同步执行编译、运行和结果比较。
